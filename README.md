## About Me

I build intelligent, scalable, and practical software products by combining modern full-stack engineering with AI-powered systems.

As a Full Stack and AI Application Developer, I design end-to-end products spanning React/TypeScript frontends, Spring Boot and FastAPI backends, relational and vector databases, and cloud deployment. I work across **RAG**, **MCP**, **Generative AI**, and **Agentic AI** workflows—building retrieval pipelines, tool-augmented assistants, and LLM-driven application features that stay grounded in real data and practical use cases. I care about clean API design, reliable data models, and shipping systems that solve real operational problems—not demos that only look good in a screenshot.

I am currently a Freelance Software Engineer at **ASVDF Company, Hyderabad**, delivering an SEO-friendly business website and a CRM & operations portal covering workflow automation, GPS tracking, project management, AI automation, and customer analytics.
