## About Me

I build intelligent, scalable, and practical software products by combining modern full-stack engineering with AI-powered systems.

As a Full Stack and AI Application Developer, I design end-to-end products spanning React/TypeScript frontends, Spring Boot and FastAPI backends, relational and vector databases, and cloud deployment. I care about clean API design, reliable data models, and shipping systems that solve real operational problems—not demos that only look good in a screenshot.

I am currently a Freelance Software Engineer at **ASVDF Company, Hyderabad**, delivering an SEO-friendly business website and a CRM & operations portal covering workflow automation, GPS tracking, project management, AI automation, and customer analytics.

### [DevPilot — AI GitHub Code Assistant](https://github.com/mohdirfan2509/ai-github-code-assistant)
**Spring Boot · Spring AI · RAG · pgvector · Next.js · AWS**

Context-aware repository Q&A built on a RAG pipeline: GitHub OAuth, repository indexing, semantic code search with pgvector, and streaming answers with source citations.

- Backend on **AWS EC2 + RDS**; frontend on **Vercel**
- Secure session auth, REST APIs, and production HTTPS deployment

**[Repository](https://github.com/mohdirfan2509/ai-github-code-assistant)** · **[Live Demo](https://frontend-psi-steel-22.vercel.app/)**

### [Darukaa.Earth — Geospatial Environmental Analytics](https://github.com/mohdirfan2509/darukaa-earth-project)
**React · TypeScript · FastAPI · PostgreSQL/PostGIS · Mapbox · Chart.js**

Production-style SaaS workspace for carbon and biodiversity project management—site polygons on Mapbox, PostGIS spatial calculations, KPI dashboards, and historical analytics.

- JWT auth, GeoJSON validation, Dockerized stack, GitHub Actions CI
- Deployed on **Vercel** (frontend) and **Render** (API + PostGIS)

**[Repository](https://github.com/mohdirfan2509/darukaa-earth-project)** · **[Live Demo](https://darukaa-earth-murex.vercel.app)**

### [Darukaa AI — Biodiversity Intelligence Chatbot](https://github.com/mohdirfan2509/darukaa-ai-chatbot)
**FastAPI · React · PostgreSQL/pgvector · RAG**

Evidence-validated environmental assistant that retrieves institutional knowledge, reasons across soil/climate/land-use/biodiversity signals, asks clarifying questions, and returns structured recommendations with source tracing.

- Multi-turn conversation memory and multi-metric reasoning pipeline
- Docker, automated testing, and CI/CD deployment

**[Repository](https://github.com/mohdirfan2509/darukaa-ai-chatbot)** · **[Live Demo](https://darukaa-ai.vercel.app/)**
